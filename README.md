## Styles

Styles are written in SCSS (`styles/style.scss` + partials) and compiled to `style.css`, which is what `index.html` links to and what GitHub Pages serves.

Compilation is done with the VS Code extension **[Live Sass Compiler](https://marketplace.visualstudio.com/items?itemName=glenn2223.live-sass)**:

1. Install the extension.
2. Open `styles/style.scss`, click **"Watch Sass"** in the VS Code status bar.
3. Every save recompiles `styles/style.scss` into `style.css` at the project root (workspace settings for this are in `.vscode/settings.json`).

Commit the updated `style.css` together with the `.scss` changes.
